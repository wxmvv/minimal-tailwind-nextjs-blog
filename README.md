# minimal-tailwind-nextjs-blog

简单的Next.js博客模板。

基于[Tailwind Nextjs Starter Blog](https://github.com/timlrx/tailwind-nextjs-starter-blog)。

该项目已归档，新的博客项目使用astro重构。

[minimal-astro-blog](https://github.com/wxmvv/minimal-astro-blog)

## 开发

```bash
pnpm install
pnpm dev
```

## 部署

```bash
pnpm build
```
